# ChainVLA：通过统一执行状态串联长时程操作中的 VLA 查询

> ChainVLA 用可修订的统一执行状态，把任务进度和上一动作块未执行尾部带入下一次决策。

## 研究问题

长时程 VLA 反复查询时容易丢失两个关键信息：过去观测中已经离开视野的任务进度，以及上一动作块尚未执行的运动意图。若直接沿用旧动作尾部又会使策略无法根据新观测纠错。ChainVLA 研究如何让跨查询状态既连续又可被最新证据修订。

## 核心方法

Progress Context 由 recurrent working state 和 sparse event memory 组成，保留观察到的阶段变化与离开当前视野的证据。Motion Tail 将前一轮预测中尚未执行的后缀用于构造下一轮状态和轨迹初始化。

关键设计是解码器仍在最新观测下重新生成整个 horizon，而不是锁死旧后缀；因此 motion tail 只是可修订先验。执行前缀后，新的任务进度与剩余动作再被带入下一轮，形成连续查询链。

## 主要贡献

1. 将跨 action-chunk 的进度记忆与运动连续性统一成执行状态。
2. 通过完整 horizon 重生成，使历史 motion tail 可被新观测纠正。
3. 在长时程 RMBench 与 LIBERO 上给出关键状态通路消融。

## 数据与训练

模型规模约 1.2B，实验覆盖 RMBench 与 LIBERO。项目页展示方法和结果，但没有直接代码、数据或权重链接；本轮只确认项目页可访问。

## 实验与结果

论文报告 RMBench 成功率 62.8%、LIBERO 98.8%。在 RMBench 中移除 Motion Tail 后降到 11.2%，移除 Progress Context 后降到 3.0%，表明两类跨查询信息都很关键（Ablation）。作者也明确说明部分外部基线未在统一协议下重跑。

## 局限性

外部基线点数来自各自论文，不能视为严格同配置比较；论文未报告充分的超参数敏感性，且真实机器人验证不足。两个巨大消融跌幅也值得后续独立复现。

## 为什么值得关注

它给 action chunk 之间应该传什么状态提供了清晰实现，而不是简单拉长视觉上下文，对长时程闭环 VLA 很有启发。

综合评分：81/100。把跨 action-chunk 查询的任务进度与未执行 motion tail 统一为可修订执行状态；RMBench 消融显示两条状态通路缺一都会大幅退化，并明确披露外部基线不可直接比较。
