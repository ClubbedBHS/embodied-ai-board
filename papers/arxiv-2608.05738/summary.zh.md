# In-Context VLA：通过上下文后训练与智能体工具调用赋予 VLA 语言能力

> VLA-Talker 不让策略生成自由文本推理，而让它消费工具获取的结构化、可落地语言证据。

## 研究问题

给 VLA 增加自由文本 CoT 看似能提升推理，却可能产生未落地描述、增加闭环延迟，并让大量语言 token 的监督干扰动作学习。论文提出另一种问题设定：VLA 不必学会“说出推理”，而应学会读取由外部感知工具提供、与当前任务相关的语言证据。

## 核心方法

VLA-Talker 在关键帧调用开放词汇检测器、单目深度和视觉语言模型，获取目标位置、夹爪位置、相对深度等证据，并渲染成多样化的结构化空间描述。In-context post-training 只监督动作 token，让策略学会消费未见措辞，而不承担生成长推理链的损失。

工具调用与动作策略被解耦：缺信息时由外部工具主动查询，证据一次性注入上下文。随后使用轨迹级 GRPO 和稀疏成功奖励，优化何时使用工具与最终任务成功的关系。

## 主要贡献

1. 分析自由文本 CoT 对低层闭环控制的 grounding、目标冲突和延迟问题。
2. 提出只消费 grounded language 的 in-context VLA 训练方式。
3. 把检测、深度与 VLM 组织为可调用证据工具，并在仿真和真实任务验证。

## 数据与训练

数据引擎把同一几何事实渲染为坐标、相对偏移、深度比较和方向提示等多种措辞。实验覆盖 RoboCasa-GR1、SimplerEnv、LIBERO，以及 Agibot 人形平台上的 8 个真实桌面操作任务。论文未提供公开代码或数据链接。

## 实验与结果

在匹配配置下，ICL/工具方案相对 CoT 基线取得更高或相当成功率，并显著降低推理成本；论文报告推理效率约提升 4.6 倍，相对标准行为克隆总体成功率提升接近 10%（Experiments）。真实实验覆盖抓放、开关、倾倒和插入等八类任务。

## 局限性

性能依赖外部检测器、单目深度、VLM、相机标定和启发式关键帧门控；工具错误会直接污染上下文。当前技能范围和单指令设定有限，也未公开实现以检验 API 成本与实时性。

## 为什么值得关注

它对“具身推理”提出有价值的架构选择：把语言作为可验证感知证据，而不是让控制器先写一段故事，对 agentic VLA 的实时性很关键。

综合评分：81/100。提出 VLA 应消费 grounded language 而非生成自由文本 CoT，并通过 in-context 后训练与感知工具调用注入结构化证据；覆盖三类仿真基准与 8 个真实任务，且披露工具依赖和标定要求。
