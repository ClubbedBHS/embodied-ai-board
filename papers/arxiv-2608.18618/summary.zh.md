# LabDex：面向实验室灵巧操作的分层基准

> LabDex把实验室灵巧操作按原子技能、组合技能和长流程组织，并统一真机与仿真任务定义。结果不只给总成功率，还暴露初始抓取和技能过渡是长流程失败的主要瓶颈，数据入口已提供。

## 研究问题

自动化实验室要求机器人既能操作脆弱、多样的器皿，也能执行依赖状态的长流程。既有基准往往只覆盖单步技能，难以定位复杂实验失败发生在哪一层。

## 核心方法

LabDex 用原子技能、组合任务和完整实验流程构成分层任务体系，并在真机与仿真中保持一致的任务定义，使研究者能够区分低层抓取、技能衔接与高层流程规划的瓶颈。

## 实验与结果

默认每项任务提供 200 条示范，原子任务进行每项 50 次真机试验，并跨层级比较多类策略。结果显示初始抓取和技能过渡会主导长流程失败。数据集已链接；仓库虽存在，项目页仍写 Code Coming Soon。

## 局限性与不确定性

1. 项目页仍将代码标为Coming Soon
2. 实验室对象和任务分布较专门
3. 部分长流程评测仍受低层技能失败主导
