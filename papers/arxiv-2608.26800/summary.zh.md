# Rapid On-Robot Learning for Dynamic Manipulation Skills: Robot Juggling

> 这项工作让双臂多指机器人直接在真机上用不到5分钟学习并组合五种三球杂耍模式；价值不在炫技本身，而在展示“差的先验模型+安全局部在线修正”可实现快速持续学习。

## 研究问题

Continual real-robot learning for bimanual dynamic dexterity.

## 核心方法

Combines a global prior, local memory model and mutually reachable safety set for minute-scale on-hardware learning.

## 实验与结果

Five three-ball patterns, precision analysis, safety analysis and physical-learning traces reviewed.
