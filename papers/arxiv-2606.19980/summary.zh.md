# ENPIRE：真实世界中智能体驱动的机器人策略自我改进

> 将编程智能体引入真实机器人策略自主改进：通过四模块闭环框架（环境搭建/策略改进/部署/进化），前沿编程智能体可自主训练策略在针盒整理、扎带紧固、GPU插拔等灵巧操作任务上达到99%成功率，多智能体+机器人集群显著加速学习。

## 研究问题

真实世界灵巧操作严重依赖人类监督和算法工程，成为通向通用物理智能的中心瓶颈。编程智能体在数字环境中已展示自动化算法搜索的能力，但缺少在物理世界中可重复的策略改进反馈循环。核心问题：如何构建一个使编程智能体能在真实世界自主执行"重置场景→执行策略→验证结果→改进迭代"闭环的系统？

## 核心方法

ENPIRE是一个四模块框架：(1) **Environment模块(EN)**——编程智能体通过程序化工具调用构建任务环境，包括硬安全约束（超出安全区域触发自动重置）、自动验证（从少量成功/失败演示中合成二值奖励函数，推理延迟<150ms）和自动重置（利用模块化操作技能将环境恢复至初始状态）。(2) **Rollout模块(R)**——策略接收视觉-本体感知输入并提交动作指令，结合奖励构成标准Gym API。(3) **Policy Improvement模块(PI)**——智能体查阅文献、制定假设、直接修改训练代码（BC或RL算法），基于真实世界自动验证结果优化性能。(4) **Evolution模块(E)**——多智能体+多机器人并行异步协作：N个智能体在N台机器人上测试N个假设，通过Git自主cherry-pick/合并成功训练配方。

测试了三款前沿编程智能体：Codex (GPT-5.5)、Claude Code (Opus 4.7)和Kimi Code (K2.6)。机器人平台为双臂6-DoF YAM机器人。

## 主要贡献

1. 提出ENPIRE，首个将编程智能体应用于真实机器人策略自主改进的框架（作者称）。
2. 演示编程智能体可自主组合多种学习范式（BC、RL、启发式、代码策略、VLA+工具调用）。
3. 验证多智能体+机器人集群的加速效应：8机器人将针插入任务从>1.5小时缩短至约40分钟。
4. 展示自主研究经验的跨任务迁移：针插入经验加速GPU插入策略学习。

## 数据与训练

不依赖预收集数据集。编程智能体从头开始：BC阶段使用少量人工演示（约10-50条），RL阶段通过自主rollout收集数据。奖励函数由智能体从演示视频和本体感知记录中自动合成。在RoboCasa365仿真基准上评估VLA+工具调用的协同效应。

## 实验与结果

**灵巧操作**（Section 3）：在Push-T任务中，Claude Code和Codex在约2小时内达到95%成功率（仿真），但真实世界仅Claude Code成功。在针插入任务上，策略通过BC→迭代BC→离线RL→在线RL的演进达到50连续成功。在GPU插入和扎带切割任务上展示了VLA(GR00T)+工具调用的自动集成。

**多智能体扩展**（Section 3.3）：Push-T从1到8智能体将达成1.0归一化得分的时间从约5小时缩短至2小时；针插入从>1.5小时缩短至约40分钟。但Token成本随集群规模超线性增长。

## 局限性

1. 编程智能体未充分利用机器人和GPU资源：MRU（平均机器人利用率）随集群增大而下降。
2. Token成本超线性增长：8智能体集群的总token预算远高于线性投影。
3. 环境搭建阶段仍需一次性人工反馈来优化安全约束和验证函数。

## 为什么值得关注

这是首个将"自主研究"(autoresearch)范式应用于真实机器人策略学习的系统。其核心洞察——物理世界中的可重复反馈循环——为机器人自主研究提供了缺失的抽象层。多智能体协作和跨任务经验迁移的验证，展示了编程智能体在物理世界中规模化自主改进的可行路径。
