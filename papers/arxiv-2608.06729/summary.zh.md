# AtlasVLA：面向视觉—语言—动作模型的持久世界—自我状态建模

> AtlasVLA 用持久 4D 世界状态和自我工作记忆缓解腕部单相机的视野外与进度遗忘。

## 研究问题

腕部相机视野随机械臂移动，目标一旦离开画面，反应式 VLA 就会忘记空间位置；多步任务中它也可能忘记已完成阶段。AtlasVLA 研究如何仅凭腕部视角维护持续更新的世界状态和任务进度，使动作生成不再只依赖当前帧。

## 核心方法

Persistent World State Memory 使用流式深度估计与空间反投影，把瞬时二维观测提升到全局 voxel-hash 4D 状态，并通过邻域融合和滑动窗口持续更新。Ego-Working State Memory 则编码历史自我状态与任务进度。两条记忆共同条件化 diffusion transformer 动作生成器。

世界记忆负责“东西在哪里”，自我工作记忆负责“已经做了什么、下一步是什么”。这种分工让系统在目标暂时不可见时仍能利用空间证据，并在长时程任务中避免重复或跳过步骤。

## 主要贡献

1. 明确区分腕部单相机下的空间遗忘与任务进度遗忘。
2. 提出持久 4D 世界记忆和自我工作记忆的双记忆 VLA。
3. 在 LIBERO、RLBench 和真实长时程任务中分别消融两类记忆。

## 数据与训练

实验覆盖 LIBERO、LIBERO-Long、RLBench 与真实机器人长时程任务，输入仅使用腕部相机，并依赖深度估计建立空间状态。论文未提供可验证项目页、代码或模型权重。

## 实验与结果

AtlasVLA 在 LIBERO 达到 97.6%、RLBench 达到 70.8% 成功率，并相对多视角或反应式基线在 LIBERO-Long 提升 9.4 个百分点、真实长时程任务提升 17.5 个百分点。真实任务总体为 69.5%；移除世界记忆降至 54.0%，移除自我记忆降至 56.5%（Ablation Studies）。

## 局限性

4D 状态构建需要深度、标定、空间哈希与持续更新，额外计算和误差传播成本尚需工程评估。真实任务规模有限，且没有公开实现，难以判断相对单纯增加历史上下文的公平成本。

## 为什么值得关注

它把 VLA 长时程失败具体拆成空间状态与执行进度两个记忆问题，并用系统消融说明两者都不可替代。

综合评分：82/100。以 4D 持久世界状态和 ego working memory 解决腕部单相机的视野外遗忘与任务进度遗忘；在 LIBERO、RLBench 和真实长时程任务上给出系统消融。
