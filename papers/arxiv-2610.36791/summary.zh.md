# RynnWorld-Latent：以通用潜动作条件化的跨本体世界模型

> 用与 RynnVLA 共享的潜动作条件化视频世界模型，支持数字遥操作与从人类视频合成机器人数据。

## 研究问题

机器人原生动作不兼容、人类视频缺少动作标签，使可控世界模型难以共享数据。该工作使用 RynnLAM 的三维潜动作，将异构交互视频用于共同预训练，并检验生成数据能否改善实体机器人策略。

## 核心方法

视频模型结合全局动作 token 与局部帧对齐条件路径，预测给定初始图像和动作后的视觉未来。跨本体预训练使用潜动作，目标机器人后训练后也可接受其原生控制命令。

数字遥操作直接用目标机器人动作生成示范；另一条路线编辑人类源视频的初帧，保持潜动作变化生成新机器人视频，再重定向伪动作并筛选。这两条合成数据路径分别与真实数据混合做策略训练。

## 主要贡献

1. 用潜动作作为跨人类、机器人和仿真的共享世界模型接口。
2. 同时支持交互数字遥操作和人类视频迁移合成。
3. 把预测评测延伸到两类双臂机器人上的闭环策略收益。

## 数据与训练

论文描述 23 个数据集、约 553.5M 帧的预训练，并从人类视频合成约 800 小时、84.8M 帧机器人数据。仓库 README 的数据规模与论文并不完全一致，当前以论文数字为准并保留核验项。代码和独立模型权重可访问。

## 实验与结果

约 800 小时合成语料；π0 的 LIBERO-Plus 从 53.6% 到 79.4%，π0.5 从 84.4% 到 84.8%；两类真机平台每任务 35 次测试（Tables 4–6）。

数字遥操作数据单独训练能得到非零成功率，但各项仍低于真实数据训练。较强 π0.5 的 LIBERO-Plus 增益只有 0.4 个百分点，不能把弱策略的大幅提升推广给所有模型。

## 局限性

1. 数据与额外优化算力的贡献尚未分离。
2. 合成视频与重定向动作分别生成，过滤不能保证物理一致。
3. 仓库 README 与论文描述的训练数据规模不一致，需要进一步核对。

## 为什么值得关注
