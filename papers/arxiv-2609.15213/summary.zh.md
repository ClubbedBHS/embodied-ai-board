# X-WBC：跨本体人形全身控制基础框架

> 将人类运动语义与机器人执行分开，共享 Transformer 在九类人形身体上联合训练，以轻量本体模块适配状态和动作。

## 研究问题

为每台机器人独立训练控制器，会把相似人类运动经验隔离在各本体中。X-WBC 研究共享运动语义和时间结构，同时保留机器人专属状态与动作接口，能否提升全身跟踪并统一不同控制输入。

## 核心方法

全人运动、重定向机器人参考和五点 VR 观测分别编码，再通过 token 对齐损失映射到共同命令空间。因果 Transformer 读取命令和本体状态历史，机器人专属编码器与解码器处理不同关节维度。

多个机器人在 Isaac Lab 中同时收集 rollout 并混合到 PPO 更新。模型通过失败率采样更多困难片段，同时剔除持续不可实现的动作，避免把错误重定向当作应学习的行为。

## 主要贡献

1. 把多机器人作为共同训练源学习共享全身时间结构。
2. 对齐全人体、机器人参考和低带宽五点 VR 命令。
3. 分别评估训练域跟踪、冻结外部动作与四类真实机器人部署。

## 数据与训练

训练使用约 200 小时 BONES-SEED 动作、九种仿真本体，每机器人 1024 并行环境，8 张 H100 训练约两天，控制为 50 Hz。10 月 25 日修订增加 100STYLE 外部动作测试；仓库当前只有 README 和 docs。

## 实验与结果

九个仿真本体、四类真实机器人；10 月 25 日版增加外部 100STYLE 冻结测试，800 clips 中 729 成功（91.13%），SONIC 93.00%（§4）。

800 段外部动作一次确定性测试中 X-WBC 成功 91.13%，SONIC 为 93.00%，因此不能写成所有对手上最优。四种真机部署主要定性展示，也不能当作未见形态零样本泛化。

## 局限性

1. 仓库只有 README 和 docs，不能算方法实现开放。
2. 真实部署主要定性，不是未见本体零样本迁移。
3. 不同外部系统保留各自输入接口，不能把比较视为完全等条件。

## 为什么值得关注

提供共享全身控制骨干的实证，和 VioLA 的高层指令到潜动作路线互补。
