# InDex：通过意图条件微调将 VLA 适配到灵巧操作

> InDex 把平行夹爪 VLA 的单自由度开合量重释为连续抓取意图，再用独立扩散头解码多指关节，在仿真灵巧基准达到 85.8%。

## 研究问题

预训练 VLA 多控制低自由度夹爪，直接把输出映射到高自由度灵巧手会造成动作多模态平均和策略崩溃；端到端微调又可能因少量灵巧数据破坏已有空间语义。论文研究如何保留 VLA 的臂运动与语义先验，只单独学习手指动作。

## 核心方法

第一阶段参数高效微调 VLA，使其预测机械臂轨迹及一个连续“虚拟抓取意图”。这个标量不再是夹爪开合命令，而表示从接近、包络到释放的宏观手部意图。

第二阶段冻结空间骨干，用意图条件扩散头把视觉、臂状态和该标量解码为多指关节动作。两阶段将低维语义意图与高维、多模态手指控制分开，减少灾难性遗忘。

## 主要贡献

1. 将预训练夹爪输出重释为跨形态抓取意图接口。
2. 用冻结 VLA+独立扩散手指头解耦语义与高维动作。
3. 验证不同 VLA 骨干和少量灵巧示范下的适配。

## 数据与训练

训练使用接触丰富、多阶段灵巧操作仿真数据，没有真实硬件。论文在 OpenVLA、UniVLA 等基础模型上比较直接投影与完整方法。代码、模型和数据未确认公开。

## 实验与结果

最佳设置平均成功率为 85.8%。OpenVLA 直接基线约 2.5%，加入 InDex 后 46.3%；UniVLA 从 3.8% 提高到 52.5%（Appendix A，Table 4）。消融支持两阶段解耦和意图代理的必要性。

## 局限性

只有仿真验证；单一标量意图可能不足以描述复杂手内重排和多接触模式。两阶段训练增加工程复杂度，对不同手型是否需要重新定义意图仍未知。

## 为什么值得关注

InDex 提供了一个简洁跨形态接口：不要求原 VLA 直接理解每个手指，而让它输出宏观意图。这对复用现有夹爪 VLA 很有现实意义。
