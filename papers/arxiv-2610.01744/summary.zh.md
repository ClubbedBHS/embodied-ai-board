# 3DROID：附带逐场景可靠性度量的可渲染三维机器人数据

> 为 DROID 的可渲染三维场景附上标定与逐场景可靠性证据，强调视觉真实感不等于机器人坐标正确。

## 研究问题

3D Gaussian Splatting 可能渲染得很好，却无法保持机器人坐标系中的真实尺度。对操作策略而言，这类几何漂移会直接影响动作与环境的对应。3DROID 将标定与几何可靠性作为数据的一部分。

## 核心方法

流程在重建之前审查相机外参来源，并比较无位姿、位姿条件和精修外参等组合。几何检验使用机器人 CAD/运动学投影、可测覆盖率以及与经典 stereo 深度的一致性，而不把 stereo 当作完整几何真值。

数据对每个静态场景发布可渲染高斯、深度、覆盖掩码和可靠性信息，通过 episode 名称连接原始 DROID 的视频及机器人状态；原始轨迹不在此重复发布。

## 主要贡献

1. 将可渲染机器人场景锚定到物理工作空间并显式检查标定来源。
2. 区分外观质量、机器人参考深度和 stereo 一致性及其覆盖范围。
3. 随场景提供可靠性信息，支持更有边界的数据使用与筛选。

## 数据与训练

数据包含 114 个 DROID 场景，约 110 个场景可用于相关配对评估。静态重建使用四个外部视角，不含腕部流。Hugging Face API 确认 manifest、pipeline、evaluation、许可证和场景资源入口可访问。

## 实验与结果

发布 114 个场景；110 个可评估场景中 YoNoSplat / ZipSplat PSNR 联合改善约 3.24 / 3.52 dB，但该比较同时改变外参与 pose conditioning（Tables 2–4）。

论文使用两种前馈重建骨干检验趋势。更可靠外参与 pose conditioning 共同改善外观，但单独注入不可靠位姿不能保证几何更准。此项工作没有声称提高下游策略成功率，也不提供动态、可交互物理模拟器。

## 局限性

1. 只有静态快照，不是时序交互模拟器。
2. 不声称完整场景几何真值或下游操作成功率改善。
3. 几何评估只覆盖可获得机器人表面或 stereo 支持的区域。

## 为什么值得关注

对 GSWorld/Real2Sim 路线补充关键质量控制：渲染外观、真实尺度和机器人参考几何应分别检验。
