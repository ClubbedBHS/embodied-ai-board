# SWIM：从行为学习 JEPA 世界模型应关注的状态维度

> 用离线动作预测学习状态各坐标的行为相关性，再用加权状态距离校准 JEPA 潜空间。

## 研究问题

用模拟器状态监督潜空间，可以让规划距离更有意义，但统一加权所有状态维度会重复计算冗余变量或放大无关变化。SWIM 研究能否从离线行为中学习哪些状态变化与动作最相关。

## 核心方法

门控逆动力学模型读取当前状态和未来位移，预测数据中记录的动作。通过动作预测与稀疏约束学习相对权重，再用这些权重构造状态距离，校准 SCALE 世界模型的潜空间几何。

逆动力学仅参与训练。测试时仍以图像编码和潜空间模型进行 CEM/iCEM 规划，不需要模拟器状态，也不额外运行门控模型，因此推理接口保持原样。

## 主要贡献

1. 用行为相关的动作预测学习状态距离，而非人工选特征或均匀加权。
2. 将学到的相对权重接入状态监督世界模型训练。
3. 以多任务、两种规划器及干扰状态消融检验小幅、稳定的规划收益。

## 数据与训练

实验在五项 OGBench 模拟操作任务上使用离线轨迹，分别训练状态权重和图像世界模型，并测试两类规划器。额外向状态追加结构化干扰变量，以检查模型是否学会降低无关维度的影响。未发现官方实现入口。

## 实验与结果

五项 OGBench 仿真任务、CEM 与 iCEM；较统一状态权重增加约 0.9–1.0 个百分点，报告 p<0.05；结构化干扰状态消融支持抑制无关维度（Experiments）。

作者报告平均提升约 0.9–1.0 个百分点，统计结果为 p<0.05。统计显著不代表能力边界发生大幅变化；方法目前依赖给定状态变量和所覆盖的离线行为，也只通过 SCALE 目标与模拟任务展示。

## 局限性

1. 增益较小，不能表述为显著跨越能力边界。
2. 依赖训练时提供的状态变量与离线行为覆盖。
3. 只有仿真，通过 SCALE 展示，尚无真机和其他目标验证。
4. 没有发现官方实现。

## 为什么值得关注

与 RoboJEPA 的 scaling 互补：不仅要增加模型大小，也要检验潜空间规划距离是否反映任务相关变化。
